# Sécurité

## Versions prises en charge

Seule la branche `main` est maintenue.

## Signaler une vulnérabilité

Ne pas ouvrir d’issue publique. Utiliser le formulaire privé
[Signaler une vulnérabilité](https://github.com/lucasdrs59-wq/portfolio-v2/security/advisories/new)
avec :

- la zone concernée ;
- les étapes de reproduction ;
- l’impact probable ;
- toute suggestion de correction.

Un accusé de réception est visé sous sept jours. Aucune donnée réelle,
coordonnée ou clé d’accès ne doit être jointe sans accord préalable.
