# Documentation

Ce dossier contient les règles qui rendent le projet compréhensible sans
dépendre de la mémoire d’une personne.

| Dossier | Contenu |
|---|---|
| `architecture/` | Décisions techniques et leurs compromis |
| `governance/` | Standards, archivage et confidentialité |
| `projects/` | Modèle éditorial des études de cas |
| `archive/` | Index des documents historiques conservés |

Une règle active reste dans sa section métier. Un document remplacé rejoint
`archive/YYYY/` avec son motif d’archivage et son successeur.
