# Modèle d’une étude de cas

Chaque projet public répond à la même structure.

| Champ | Question |
|---|---|
| Titre | Quel système ou résultat a été construit ? |
| Résumé | Pourquoi le sujet mérite-t-il l’attention ? |
| Enjeu | Quel problème concret fallait-il résoudre ? |
| Démarche | Quelles étapes rendent le raisonnement vérifiable ? |
| Livrables | Qu’est-ce qui existe à la fin ? |
| Résultats | Qu’est-ce que cela rend possible ? |
| Métriques | Quels repères chiffrés sont publiables ? |
| Confidentialité | Qu’est-ce qui a été anonymisé ? |

## Règles éditoriales

- commencer par le problème, jamais par une liste de technologies ;
- distinguer résultat mesuré, résultat attendu et simple capacité ;
- ne pas revendiquer un gain non démontré ;
- utiliser des verbes concrets ;
- expliquer les limites et les prochaines étapes ;
- employer exclusivement des données publiques ou synthétiques.
